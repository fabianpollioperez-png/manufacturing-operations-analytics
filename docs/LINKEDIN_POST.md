# LinkedIn post

I built an end-to-end Manufacturing Operations Analytics project to demonstrate how I use data to identify operational losses and prioritize continuous improvement opportunities.

The project analyzes 5,475 production records across five manufacturing lines and three shifts using Python, SQLite, SQL, and Power BI.

Key findings:

- Line 5 - Finishing was identified as the primary improvement opportunity, with the lowest target attainment (72.9%), highest scrap rate (4.9%), and highest downtime (87,191 minutes).
- Quality Hold was its largest downtime category.
- Shift 3 recorded the highest scrap rate at 5.6%.
- SQL exception logic was used to flag critical line-month combinations for management attention.

The solution includes a dimensional data model, eight business-focused SQL queries, data-quality controls, automated exception reporting, and two Power BI report pages covering executive performance and root-cause analysis.

This project reflects the kind of work I enjoy most: combining industrial engineering, data analytics, and continuous improvement to turn operational data into actionable priorities.
