# LinkedIn project entry

## Title

Manufacturing Operations Analytics | SQL, Python & Power BI

## Description

Built an end-to-end manufacturing analytics solution using Python, SQLite, SQL, and Power BI. Analyzed 5,475 production records across five production lines and three shifts to evaluate OEE, target attainment, scrap, downtime, and operational bottlenecks. Developed eight business-focused SQL queries, automated data-quality controls, and exception logic to identify critical operational conditions. The analysis identified Line 5 - Finishing as the primary improvement opportunity and isolated its main loss drivers by downtime category and shift.
